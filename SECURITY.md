# Security Policy

## Supported Versions

Only the latest release of `bopscrk` is supported. Please ensure you are running the most up-to-date version before reporting a vulnerability.

| Version | Supported          |
| ------- | ------------------ |
| >= 2.4  | :white_check_mark: |
| < 2.4   | :x:                |

## Reporting a Vulnerability

We take the security of `bopscrk` seriously. If you find a security vulnerability, please do not disclose it publicly. Instead, report it privately to the maintainer:

* **Email:** r3nt0n@protonmail.com

Please include the following details in your report:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or a proof-of-concept (PoC) to reproduce the issue.
- Details about your environment (Python version, operating system, version of `bopscrk`).

You should receive an acknowledgment within 48 hours. We will coordinate a fix and release a patched version before disclosing the vulnerability publicly.
